# Market Talk

بداية نظيفة لصفحة عربية باتجاه RTL. لا يوجد محتوى أو تصميم في الصفحة حاليًا.

## الإعدادات الأساسية

- Tailwind CSS عبر CDN، وإعداداته المخصصة داخل `index.html` قبل تحميل المكتبة.
- CSS الأساسي والحالات الخاصة النادرة في `src/css/style.css`.
- الهوية اللونية: الأزرق `#1E3A8A` والأصفر `#E9BA00`.
- خط النصوص: `Lyon Arabic Text`؛ وخط العناوين: `Lyon Arabic Display`. ملفات الخطوط المحلية مربوطة من مجلد `assets/Fonts/Lyon`.

تُفتح `index.html` عبر Live Server أو خادم ملفات ثابت. يحتاج Tailwind CDN إلى اتصال بالإنترنت؛ ملفات الخطوط محلية.
